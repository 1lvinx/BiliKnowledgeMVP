# 收藏夹留不住知识，所以我做了哔知

**文 / 逸峰AI**

我一直是 B 站重度用户，AI、大模型、编程、开源项目、产品设计，只要看到有价值的视频，就会顺手收藏。最开始我以为收藏是一种积累，后来才发现，收藏夹越来越长，真正重新打开的次数却越来越少。很多内容明明看过，真正需要时却想不起标题、UP 主和关键词，最后只能重新搜索，甚至直接放弃。

问题不在视频，而在沉淀方式。视频是很好的知识入口，它直观、容易理解，也适合演示操作；但视频不适合检索和复用。看完一个二十分钟视频，当时觉得很有收获，过几天只剩下一个模糊印象。收藏夹更像仓库，能装下内容，却不能自动变成知识库。

我做哔知，就是想把这个断点补上。它不追求自动总结所有收藏，而是围绕一条更朴素的链路：选择值得留下的视频，获取字幕或本地转写，用 AI 提炼洞察，再生成一份结构化 Markdown 笔记。如果视频里提到 GitHub 项目，也尽量把仓库识别出来，放进开源候选，方便后续继续研究。

这套流程的重点不是让 AI 替我学习，而是让 AI 处理那些重复、机械、容易让人放弃的部分。真正的判断仍然属于用户：这条视频值不值得处理，笔记是否准确，标签怎么打，未来是否要继续深入。这样每天整理 5 到 10 条高价值视频，比一次性批量生成几千条空泛摘要更有意义。

哔知目前还在 Beta 阶段，但它已经开始进入我的日常工作流。收藏夹不再只是“以后再看”的心理安慰，而是可以被逐步加工成字幕、洞察、笔记和可复用资源。对我来说，这就是它最初的价值：把看过的视频，真正变成以后能找到、能理解、能继续使用的知识资产。
