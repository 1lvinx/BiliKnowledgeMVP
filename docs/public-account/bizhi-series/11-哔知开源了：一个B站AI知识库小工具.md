# 哔知开源了：一个 B 站 AI 知识库小工具

**文 / 逸峰AI**

这段时间我一直在做一个小工具，名字叫「哔知」。它不是一个商业团队包装出来的完整产品，而是我利用工作之余，为自己的真实知识工作流慢慢打磨出来的个人业务项目。今天先把 Beta RC 版本开源出来，欢迎感兴趣的朋友围观、试用和提建议。

哔知想解决的问题很具体：B 站收藏夹保存的是视频入口，但很难保存知识本身。很多 AI、编程、开源项目视频当时看完很有启发，过几天真正要用时，只记得“好像看过”，却想不起标题、项目名、命令和关键限制。收藏越来越多，能复用的内容反而越来越少。

所以哔知的核心思路不是“一键总结所有收藏”，而是把真正值得留下的视频沉淀成本地知识资产。它的流程是：选择视频，获取字幕或本地转写，生成洞察，整理成 Markdown 笔记，再把视频里提到的 GitHub 项目识别出来，放进开源候选池。AI 负责整理、提炼和结构化，用户负责判断、取舍、打标签和继续研究。

目前这个版本已经能完成基础闭环：收藏夹与手动添加、字幕抓取、本地 ASR、洞察生成、Markdown 笔记、开源项目识别、Token 用量记录、Doctor 环境诊断，以及 macOS、Windows、Linux 安装包自动构建。每个安装包也附带 SHA256 校验文件，方便确认完整性。

我自己的使用节奏很克制：每天只处理 5 到 10 条真正值得沉淀的视频，优先处理 15 秒到 30 分钟内容。因为知识库不是越满越好，真正重要的是以后还能搜索、理解和复用。

后续开发会按 V2 蓝图推进，目标是把哔知从“B 站收藏整理工具”升级成真正的 AI 视频知识工作台。第一阶段先做稳定性、收藏导入和全局搜索，目标是 5000+ 收藏可稳定导入，搜索结果能快速命中视频、笔记和项目线索。第二阶段强化 AI 摘要、AI 标签、分类和知识卡片，让每条视频都能沉淀成更精炼的知识单元，而不是一篇泛泛的总结。第三阶段会做知识图谱和本地 Embedding，把视频、标签、项目、笔记和想法连接起来，帮助用户看到知识之间的关系。第四阶段会尝试 Agent 问答和 RAG，让用户可以围绕自己的视频知识库提问。更后面才考虑插件、同步和商业化，不会过早做团队协作、复杂权限和社交功能。
